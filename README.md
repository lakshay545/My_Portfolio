# Lakshay Sharma - Personal Portfolio

Welcome to the source code of my personal portfolio website! This project showcases my journey, skills, and the projects I've built as a Full-Stack Developer and AI/ML Enthusiast.

You can view the live website here: [Lakshay Sharma Portfolio](https://github.com/lakshay545/My_Portfolio)

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel

## ✨ Key Features

- **Custom Terminal Chatbot:** An integrated, interactive terminal-style chatbot that answers questions about my background, skills, and projects based on predefined logic.
- **Modern UI/UX:** A sleek, dark-themed interface with glassmorphism effects, dynamic routing, and smooth scroll animations.
- **Responsive Design:** Fully optimized for a seamless experience across mobile, tablet, and desktop devices.
- **Email Integration:** A custom-styled contact form connected securely to an email provider to receive direct messages.

## 🚀 Running Locally

If you'd like to run this project on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lakshay545/My_Portfolio.git
   cd My_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
